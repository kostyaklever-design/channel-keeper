# Установка

[English](INSTALL.md)

Три способа, каждому нужен только токен бота от @BotFather. После любого из них: сделать бота админом и отправить `/setup` ([шаги 3–5 ниже](#после-любого-способа-права-setup-команды)).

## Railway
Без своего сервера, всё в браузере. Railway платный по потреблению, цены — railway.com/pricing.

**В один клик:** [![Deploy on Railway](https://railway.com/button.svg)](https://railway.com/deploy/channel-keeper) → войти → вставить токен в `BOT_TOKEN` → **Deploy**. Railway сам создаст проект и том `/data`. Дальше — [шаги ниже](#после-любого-способа-права-setup-команды).
Бот при этом работает с настройками по умолчанию — на своём языке (русском, если ваш Telegram на русском). Чтобы поменять их (стоп-слова, тексты бота в чате, русские тексты из `examples/keeper.ru.yaml`), положите `keeper.yaml` в свой маленький приватный репозиторий и укажите его в переменной `CONTENT_REPO` ([CONFIG](CONFIG.ru.md#контент-в-отдельном-приватном-репозитории-по-желанию)).

**Вручную** — если нужна своя копия кода (чтобы править `posts.yaml` и `keeper.yaml` на GitHub):

**1. Своя копия кода на GitHub** — приватная, потому что `posts.yaml` — это ваш контент-план.
- На странице этого репозитория нажмите **Use this template → Create a new repository**, выберите **Private**, **Create repository**.
- Нет такой кнопки? Скачайте архив из **Releases**, затем GitHub → **New repository** → **Private** → **Create** → **uploading an existing file** → перетащите всё из архива → **Commit changes**.

**2. Проект Railway из этого репозитория.**
Railway → **New Project → Deploy from GitHub repo** → разрешите доступ к этому репозиторию → выберите его. Начнётся первая сборка; без токена она может упасть — это нормально.

**3. Токен.**
Нажмите на сервис → **Variables → New Variable** → имя `BOT_TOKEN`, значение — токен от @BotFather → **Add**.

**4. Память бота — обязательно.**
Правый клик по сервису на схеме проекта (или **Ctrl/⌘ K**) → **Attach Volume** → путь **`/data`**. Без этого бот забывает всё при каждом деплое, включая `/setup`.

**5. Деплой.**
Нажмите **Deploy** (Railway показывает кнопку после изменений). В **Deployments → View logs** должна появиться строка `Channel Keeper v… starting, not set up yet`. Дальше — [шаги ниже](#после-любого-способа-права-setup-команды).

## Docker
```
docker build -t channel-keeper .
docker run -d --name channel-keeper --restart unless-stopped \
  -e BOT_TOKEN=123456:ABC... \
  -v channel-keeper-data:/data \
  channel-keeper
```
- Том `channel-keeper-data` хранит память бота между обновлениями.
- Логи: `docker logs -f channel-keeper`.
- Обновление: `docker build -t channel-keeper .`, затем `docker rm -f channel-keeper` и тот же `docker run` — память остаётся в томе.
- Ваши `posts.yaml`, `keeper.yaml`, `sources.yaml`: правьте их в папке до `docker build` или держите в отдельном репозитории через `CONTENT_REPO` ([CONFIG](CONFIG.ru.md)).

## Свой сервер
Debian или Ubuntu, с sudo.
```
unzip channel-keeper-*.zip -d channel-keeper && cd channel-keeper
sudo bash install.sh
```
Скрипт ставит Python, создаёт системного пользователя `keeper`, кладёт код в `/opt/channel-keeper`, спрашивает токен (ввод скрыт) и хранит его в `/etc/channel-keeper.env`, доступном только root, и запускает сервис `channel-keeper`.
- Логи: `journalctl -u channel-keeper -f`.
- Обновление: распакуйте новую версию и снова `sudo bash install.sh` — токен и память в `/var/lib/channel-keeper` сохранятся.
- Настройки: правьте `/opt/channel-keeper/keeper.yaml` и другие файлы контента; бот перечитывает их за 5 минут.

## После любого способа: права, /setup, команды

**3. Сделайте бота админом.** У канала должна быть группа обсуждения (Канал → Изменить → **Обсуждение**).
- **Канал** → Администраторы → **Добавить администратора** → найдите бота → оставьте включённым только **Публикация сообщений** → Сохранить.
- **Группа обсуждения** → Администраторы → **Добавить администратора** → бот → только **Удаление сообщений** и **Блокировка пользователей** → Сохранить.

Дополнительно, только если пользуетесь этим:
| Функция | Где | Право |
|---|---|---|
| Закреп рекламных постов, удаление по таймеру | Канал | Изменение сообщений, Удаление сообщений |
| Сообщения и предложенные посты каналу | Канал | Управление личными сообщениями (Manage direct messages) |
| Капча до входа (группа с «Одобрением новых участников») | Группа | Добавление участников |

**4. `/setup`.** Откройте бота в личке → **Start** → `/setup`. Кто сделал это первым, становится владельцем. Нажмите свой канал, потом группу: бот проверит права и перечислит, чего не хватает. `/setup` можно отправить снова в любой момент, чтобы перепроверить.

**5. Язык и меню команд.** Ничего делать не нужно: бот сам настраивает кнопку «Меню» и говорит по-русски, если ваш Telegram на русском, иначе по-английски. Сменить: `/lang ru`, `/lang en` или `/lang auto`.

**Первый пост:** отправьте боту в личку любой текст → **✅ Опубликовать**.

**Дальше, по желанию:**
- русские тексты бота в чате и ваши настройки — скопируйте `examples/keeper.ru.yaml` в `keeper.yaml` ([SETTINGS](SETTINGS.ru.md));
- ваш YouTube, блог и новости — `sources.yaml` ([SOURCES](SOURCES.ru.md)), пример на русском — `examples/sources.ru.yaml`;
- ИИ — `/setup` → **🔑 Добавить ключ ИИ**, вставьте ключ OpenAI или Anthropic ([AI](AI.ru.md)).

## Если что-то не так
| Видите | Сделайте |
|---|---|
| `Forbidden: bot is not a member of the channel chat` в логах | Добавьте бота админом **канала**, а не только группы. |
| После каждого деплоя бот снова просит `/setup` | Нет тома на `/data` (Railway, шаг 4). |
| `Cannot write the bot's memory in /data` | Процесс не может писать в папку. На Railway: сервис → **Settings → Build → Builder** = Railpack, затем передеплой. |
| Бот молчит в личке | Публиковать могут только владельцы. `/id` покажет ваш id; он должен быть в `ADMIN_IDS`, либо ещё никто не отправил `/setup`. |
| «The AI provider refused the key: …» | Дальше — слова самого провайдера. Обычно ключ скопирован не целиком или у ключа нет доступа к моделям. |
| Пост ждёт в `/queue` | Причина написана рядом: тихие часы, лимит в день, интервал или 3 новости подряд. |
