# Настройки канала — keeper.yaml

[English](SETTINGS.md)

Настройки, которые не являются секретами. Файл необязателен: без него бот берёт свои значения по умолчанию на языке бота (английском или русском — см. `language`). Что вы впишете сюда, остаётся ровно как написано; значение, совпадающее с английским по умолчанию, всё равно следует языку. Готовый русский пример — `examples/keeper.ru.yaml`.
Правьте на GitHub (значок карандаша) → **Commit**. Бот применяет изменения в течение 5 минут.
Если в файле ошибка, бот оставляет прежние настройки и пишет причину в лог; проверка на GitHub тоже становится красной.

```yaml
timezone: Europe/Amsterdam   # часовой пояс для posts.yaml

spam_words:                  # сообщения с любым из этих слов удаляются
  - casino
  - крипта

warn_seconds: 60             # сколько предупреждение висит в чате (5–3600)

messages:                    # слова бота в чате, на любом языке
  warn: "{name}, ссылки и реклама здесь запрещены. В следующий раз — бан."
  ban: "{name} удалён за повторный спам."

channel_rules:               # для постов из лент, см. SOURCES.ru.md
  daily_limit: 6             # постов в день в канале, всех видов; 0 = без лимита
  quiet_hours: "23:00-08:00" # ночью из очереди ничего; off = без тихих часов. Кавычки обязательны
  news_in_a_row: 3           # правило 1 : 3 — четвёртая новость ждёт вашего поста; 0 = выкл
  gap_minutes: 30            # между двумя постами из очереди; 0 = выкл

captcha:                     # см. MODERATION.ru.md
  enabled: true              # все, кроме админов, один раз нажимают «Я человек»; false = выкл
  seconds: 120               # время на нажатие (15–600), потом человек удаляется (может вступить снова)
  text: "{name}, нажмите кнопку в течение {seconds} секунд, чтобы писать в этом чате."
  button: "Я человек"

channel_messages: block      # сообщения «от имени канала»: block или check, см. MODERATION.ru.md

flood:                       # off = без ограничения флуда
  messages: 5                # столько сообщений ...
  seconds: 10                # ... за это время -> только чтение
  mute_minutes: 10

first_minutes: 0             # 5 = в комментариях нового поста первые 5 минут пишут только знакомые; 0 = выкл

keep_days: 90                # строки журнала старше этого удаляются (7–3650)

ai_moderation: true          # с ключом ИИ: первые комментарии новичков получают второе мнение (см. AI.ru.md)

probation:                   # off = без испытательного срока
  messages: 2                # настоящих сообщений до того, как разрешены картинки без текста, пересылки, контакты
  min_length: 15             # сообщения короче не считаются

profile_check: true          # ссылка или стоп-слово в профиле новичка -> решают владельцы (Удалить / Оставить)

ad_label: Реклама            # первая строка поста с пометкой «реклама» (📣 под превью); по умолчанию — на языке бота

join_requests: captcha       # когда группа одобряет новых участников: captcha | owners | off (см. MODERATION.ru.md)

learning_filter: true        # учится на ваших Удалить / Оставить; только спрашивает, никогда не удаляет

read_more: "Читать на {source} →"   # короткая ссылка под новостью из ленты; {source} = сайт
ai_language: Russian         # язык пересказов ИИ; по умолчанию — язык бота
language: auto               # язык бота: auto (Telegram владельцев), en или ru. Тексты в чате по умолчанию,
                             # капча, «Реклама» и «Читать на …» следуют ему, если вы не задали своё
```

- В `messages` есть ещё `flood`, `first_minutes` и `probation` — подсказки для этих правил.
- `{name}` превращается в упоминание человека (его @username или имя со ссылкой на аккаунт), поэтому Telegram уведомит его даже без username. Других подстановок нет.
- `spam_words` полностью заменяет встроенный список — скопируйте значения по умолчанию, которые хотите оставить.
- Неизвестные настройки отклоняются, чтобы опечатка не молча ничего не делала.

## Правила канала
`channel_rules` решают, когда посты из лент выходят из очереди ([как устроена очередь](SOURCES.ru.md#очередь-и-правила-канала)). Без этого блока действуют значения выше. Время — в `timezone`. Посты, которые вы пишете в `posts.yaml`, эти правила никогда не придерживают, но учитывают.

## Капча
Включена по умолчанию. Касается всех участников: новичков при вступлении, старых — при первом сообщении; в первые часы ждите волну кнопок. В `text` можно использовать `{name}` (упоминание, которое уведомит человека) и `{seconds}`; язык любой. Как она работает — [MODERATION](MODERATION.ru.md#капча).

## Сообщения от имени канала
Telegram позволяет любому писать в группе обсуждения «от имени» своего канала. Спамеры это любят: канал не может нажать кнопку капчи, и у него нет личного аккаунта, который можно забанить.
- `block` (по умолчанию) — каждое такое сообщение удаляется; первый раз с предупреждением, второй — канал банится в группе. Ваш собственный канал и анонимных админов это не касается.
- `check` — такие сообщения проверяются как у всех: удаляются только ссылки, пересылки и стоп-слова. Выбирайте, если честные блогеры комментируют от имени своих каналов.
