# Ленты — sources.yaml

[English](SOURCES.md)

Бот проверяет ваши ленты каждые 15 минут и приносит в канал новые записи: ваши видео с YouTube и статьи блога, новости по поисковому запросу, Google Alerts, любую ленту RSS или Atom.
Файл необязателен. Правьте на GitHub (значок карандаша) → **Commit**; бот применяет изменения в течение 5 минут. При ошибке остаются прежние ленты, а проверка на GitHub становится красной. Готовый русский пример — `examples/sources.ru.yaml`.

```yaml
sources:
  - id: my-youtube              # маленькие латинские буквы, цифры, - или _
    type: youtube
    channel: UCxxxxxxxxxxxxxxxxxxxxxx
    name: Наш YouTube           # как источник называется в черновиках и /sources

  - id: blog
    type: rss
    url: https://example.com/feed.xml
    mode: draft                 # сначала спросить меня

  - id: ai-news
    type: google_news
    query: "ИИ-агент"           # что вы набрали бы в Google News
    lang: ru                    # язык новостей
    country: UA
    per_day: 3                  # не больше 3 черновиков в день из этого источника

  - id: alerts
    type: google_alerts
    url: https://www.google.com/alerts/feeds/00000000000000000000/0000000000000000000
```

## Поля

| Поле | Обязательно | Что делает |
|---|---|---|
| `id` | да | Ваше имя источника. Если его поменять, это будет новый источник. |
| `type` | да | `youtube`, `rss`, `google_news` или `google_alerts`. |
| `channel` | youtube | Id канала, 24 символа, начинается с `UC` (см. ниже). |
| `url` | rss, google_alerts | Адрес ленты, начинается с `https://`. |
| `query`, `lang`, `country` | google_news | Слова поиска; язык и страна выдачи (по умолчанию `en`, `US`). |
| `label` | нет | `own` — ваш контент; `news` — чужие статьи. По умолчанию: `own` для youtube и rss, `news` для Google News и Alerts. |
| `mode` | нет | `auto` — сразу в очередь; `draft` — сначала превью в вашей личке. По умолчанию: `auto` для своего, а новости **всегда** `draft`. |
| `template` | нет | Как выглядит пост. Поля: `{title}`, `{link}` (адрес), `{source}`, `{read}` (короткое «Читать на dev.by →» со спрятанным адресом — текст из `read_more` в `keeper.yaml`). `{link}` или `{read}` обязательно. По умолчанию для своего: заголовок, пустая строка, ссылка (Telegram покажет карточку видео или страницы). Для новостей: заголовок, пустая строка, `{read}`. |
| `per_day` | нет | Не больше стольких записей в день из источника (1–50). По умолчанию: 10 для своего, 3 для новостей. Лишние пропускаются. |
| `name` | нет | Как источник называется в сообщениях. По умолчанию — id. |

**Где взять id канала YouTube:** YouTube → ваш канал → **О канале** (или описание канала) → **Поделиться** → **Скопировать идентификатор канала**. Имя вида `@name` не подходит: ленте нужен id.

**Где взять ленту Google Alerts:** google.com/alerts → создайте оповещение → **Показать параметры** → **Куда отправлять: RSS-лента** → **Создать оповещение** → значок RSS рядом с ним → скопируйте адрес.

## Картинки и пересказ
- Если лента даёт картинку к записи (превью YouTube, большинство блогов, Хабр), пост уходит с ней. Если Telegram не может скачать картинку, пост уходит текстом.
- В черновике новости — **✨ Пересказать своими словами** (нужен ключ ИИ): ИИ читает статью и пишет 2–3 предложения своими словами на `ai_language` (по умолчанию — язык бота); пост становится заголовок + пересказ + «Читать на …», и вы получаете новое превью. Уникальный текст, ничего не скопировано. Google News даёт в ленте только заголовок: там ИИ пишет по заголовку — что сообщает источник (со ссылкой на него), общий контекст и почему это важно — и ему запрещено придумывать подробности события. Превью предупреждает, что текст нужно проверить перед публикацией.

## Что обещает бот
- **Старое в канал не вываливается.** Когда источник новый — или у него поменялся адрес — всё, что уже есть в ленте, помечается просмотренным. Приходят только записи, появившиеся после этого.
- **Ничего дважды.** Одна и та же новость из двух лент (та же ссылка или тот же заголовок) приходит один раз. Записи старше 3 дней не публикуются никогда.
- **Чужие новости — только по вашему нажатию.** Новость никогда не публикуется сама: вы получаете черновик с заголовком, ссылкой и местом для своего комментария ([черновики](POSTS.ru.md#черновики)). Текст чужой статьи бот никогда не копирует.
- **Одна сломанная лента не останавливает остальные.** Ошибка видна в `/sources` и в логе.

## Очередь и правила канала
Посты из лент попадают в очередь и выходят из неё по одному, когда позволяют правила канала. Правила лежат в `keeper.yaml` в блоке `channel_rules` ([настройки](SETTINGS.ru.md#правила-канала)):

- **Тихие часы** — ночью из очереди ничего.
- **Лимит в день** — не больше N постов в день в канале, считаются все виды.
- **Правило 1 : 3** — не больше 3 чужих новостей подряд; следующая ждёт вашего поста. Канал остаётся вашим, а не агрегатором новостей.
- **Интервал** — не меньше N минут между двумя постами из очереди.

Когда новость ждёт из-за правила 1 : 3, вы получаете одно тихое сообщение с кнопками **✅ Опубликовать всё равно** и **🗑 Пропустить**. Если ничего не делать, она выйдет сама после вашего следующего поста. Новость, ждущая больше 72 часов, уходит из очереди.

В черновике из ленты **✅ Опубликовать** тоже соблюдает правила: если правило придерживает пост, он идёт в очередь, а вы получаете **Опубликовать всё равно** — нарушить правило можно только вторым, осознанным нажатием. **🗓 В очередь** ставит его в очередь.

Посты, которые вы пишете в `posts.yaml`, — ваши: они выходят в своё время и никогда не придерживаются, но засчитываются в дневной лимит и прерывают серию новостей.

`/queue` показывает, что ждёт и почему; `/sources` — как дела у каждой ленты.
